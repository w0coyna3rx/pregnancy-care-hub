# “跳操女孩们”，你们的盆底还好吗？

> 更新时间：2026-09-16 (UTC+8)

就跟着练了起来。

还有的人跳着跳着漏尿了？

为什么产后妈妈的你不适合呢？

妊娠期随着子宫增大及妈妈体重增加，重力作用方向由未孕状态的骨盆前移至盆底肌，盆底肌肉、筋膜长期慢性牵拉，造成不同程度的软组织损伤；妊娠期松弛素等激素水平变化改变了盆底结缔组织的胶原代谢，导致盆底支持结构松弛。分娩时盆底受胎头挤压，盆底拉伸延长。所以，**漏尿、腰痛、脱垂是产后女性的三大困扰**。

“毽子操”里面有大量类似踢毽子的动作，主要是对针对髋关节、腰腹部的训练。但是，如果产后妈妈本身有盆底功能降低、耻骨联合疼痛、腹直肌分离等问题，剧烈跳动会增加漏尿和器官脱垂的风险。不仅仅是产后妈妈，还有中老年女性也要量力而行。

**产后小贴士**

产后妈妈们增加腹压的动作都要暂缓，比如仰卧起坐、卷腹、久蹲久站、负重、长期便秘、慢性咳嗽、跑跳等剧烈运动等。这些动作会徒增盆底肌的负担，加重盆底损伤，**脏器脱垂、压力性尿失禁等盆底疾病**也会随之出现。

运动健身要循序渐进，量力而行。而对于我们的特殊群体——产后宝妈们来说，更是需要谨慎跟练，**跟练前最好能评估一下盆底功能，腰腹部、膝关节的情况**，毕竟我们希望在收获健康的同时，也要避免受伤。如果宝妈不确定自己是否可以跳“毽子操”，可以向专业的医生咨询。

**子宫脱垂**
它是常见的脏器脱垂症状之一，是指子宫从正常位置沿阴道下降，甚至脱出阴道之外。常见于经历过一次或多次阴道分娩的绝经后女性。
**临床表现**
子宫下垂往往会对生活造成一定影响，轻度的脱垂可能没有明显的表现，平时没什么感觉；中度的脱垂可有腰骶部酸痛或下坠感，并有肿物自阴道脱出，部分患者伴有尿失禁、排尿困难等尿路症状和便秘等症状；重度的脱垂当下垂子宫脱出体外时，还可能会因摩擦造成其破溃出血等，严重者甚至会发生癌变。
**子宫为什么会掉下来**

1.妊娠分娩损伤是子宫脱垂发病的主要原因。

2.肥胖和腹压增加，如长期慢性咳嗽，便秘等增加盆腹腔压力。

3.年龄和绝经，激素水平降低，盆底肌张力机能减退。

4.家庭遗传和其他因素。
**改善方法**

1. 产后42天恶露干净后，进行常规盆底功能筛查，早预防、早发现、早治疗；

2. 轻度脱垂可进行盆底肌康复，严重者建议盆底手术治疗，术后进行盆底功能康复；

3. 辅助治疗：子宫托、WAFF运动康复；

4. 居家康复：盆底康复器训练（阴道哑铃）、凯格尔运动等。
