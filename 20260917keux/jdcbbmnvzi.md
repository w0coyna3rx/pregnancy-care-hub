# 新冠康复系列10 | 新冠感染患者认知功能障碍的居家康复

> 更新时间：2026-09-17 (UTC+8)

{ 点击蓝字，关注我们 }

新冠病毒感染后的症状使我们饱受煎熬，但“阳康”后仍觉得自己脑子迟钝了好多、做事情总“卡壳”、记忆力下降、言语表达能力变差，这些是新冠病毒感染的后遗症吗？会持续多长时间？是否会痊愈？今天我们一起来了解“脑雾”。

“脑雾”（Brain Fog）是患者用来描述注意力不集中、记忆力下降、脑子转不动的用语。“脑雾”的字面意思也很形象：脑海就像被浓雾笼罩。

在日常生活中，我们都曾有过脑雾，只是很快会恢复。比如熬夜晨起后，明明感觉很累还要强撑着上班，感觉大脑被提走了灵魂，做事、说话颠三倒四，无法集中注意力。

脑雾并不是一个医学术语或科学术语，而是对一类谈不上症状感觉的描述，就是感觉脑子转不动了，具体是指新冠病毒感染后一系列认知症状，包括注意力不集中、一头雾水、反应变慢、思考力不够、爱忘事、疲惫、倦怠，总之就是什么也没做，但是感觉很累的认知感受。

这种“脑子不转了”的主观体验，在新冠病毒感染的患者中很常见。目前还没弄清为什么出现这些症状，有研究猜测新冠病毒可能会影响脑细胞，或者是影响了脑供血，有可能是感染后的免疫连锁反应。不过不必担心，已基本达成共识，“脑雾”更像是一种认知障碍，而不是类似痴呆症的大脑结构损伤，也就是说，新冠病毒感染后的大脑卡壳是可逆转的，绝大多数可恢复。

**大脑怎样才能尽快恢复？**

**一．多休息，尽量少消耗。**我们该如何放松大脑，以下是WHO给出的建议：深呼吸、放松、放轻松，然后开始问自己五个问题，每个问题至少思考10秒。

A.我眼前能看到的5样东西是什么？

B.我能感受到的4种感觉是什么？

C.我能听到的3种声音是什么？

D.我能够闻到的2种气味是什么？

E.我能品尝到的1种口味是什么？

你如果可以感到呼吸平缓、心情平静，那么说明这个方法可行；要是没什么特别感受，可以尝试冥想、散步、锻炼，总之，让自己感到舒适、放松即可。

**二．减少干扰。**尝试在安静环境中工作，如有必要可使用耳塞。

**三．列“课表”。**将每日需要做的事情按照时间顺序进行罗列。在不太疲倦时完成需要思考力的工作，在上午完成需要体力较大的工作。如果疲劳使身体不舒服，请缩短时间并休息。一次只做一件事，切莫急于求成或试图一次获取过多信息。当某一项工作完成时，适当给自己奖励。

**四．进行脑力锻炼。**可以尝试新的爱好，通过拼图、文字游戏、记忆联系来帮助思考，或通过具有一定挑战性但仍可完成的脑力活动开始（成功率80%），并逐步增加难度。

**五．保证充足睡眠，避免抽烟、饮酒。**睡前尽量不玩手机，不做剧烈运动，少进食。

最后，相信我们的大脑，它具有无限潜力且聪明绝顶，我们只要保持良好心态，吃好、休息好，剩下的就交给身体吧！
